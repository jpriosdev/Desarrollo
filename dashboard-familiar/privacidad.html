Política de privacidad

Dashboard familiar es una app privada para una sola familia. Esta página explica qué datos de Google usa y qué hace con ellos.

Qué datos usa

  • Google Tasks: lee una lista de compras, marca tareas como hechas y agrega tareas nuevas.
  • Google Calendar: responde (acepta o rechaza) invitaciones de un calendario familiar.

Dónde quedan

Los datos se procesan en un equipo dentro de la casa de la familia y solo se muestran en las pantallas de esa casa. No se guardan en servidores externos, no se venden, no se comparten con terceros y no se usan para publicidad ni para entrenar modelos.

Cómo revocar el acceso

El acceso se puede quitar cuando se quiera desde la página de permisos de la cuenta de Google.

Uso de los datos de Google

El uso de la información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
